## 5. SRM 高 loss 与 nan

本地 DeepfakeBench 的 srm_detector.py 和 loss/am_softmax.py 确认：SRM 使用 AM-Softmax，m=0.45、s=30、gamma=0、t=1。正确类别分数减去 0.45 后，全部分数乘以 30 再计算交叉熵。

二分类分数差为 gap 时，loss = log(1 + exp(30 × (0.45 - gap)))。两类分数相同时约为 13.5，因此十几不能单独判断为异常，也不能直接和其他模型普通 CE/BCE 的绝对值比较。

已核对完整 10 轮：SRM 平均 loss 从 6.0416 降到 1.5567，日志中的 loss 和最终权重未发现 NaN/Inf。保留原生损失；这是数据有效性验收，不代表已完成检测性能评估。

step 41、81 仅 AI 相关域对为 nan，mean_cos 有限，与缺失域占位一致：rank 0 本地 batch 中某域不足 2 个样本会跳过，冲突率只计算有效域对。具体样本数待核实；若 loss 或参与计算的梯度也出现非有限值，应另行排查数值问题。
