# 本项目已完成模型与待补 checkpoint 清单

核对日期：2026-11-19。范围是 `linear_probe-and-gradient` 项目的 OpenMMSecV2 四域联合训练、逐轮表征秩和分域梯度记录。这里的“完成”指本项目实验完成，不是模型原生 benchmark 的推理测试，也不是 CPU 前向预检。

本文初版链接从本地官方 README、模型说明或源码摘录。2026-11-19 已按用户授权访问 A40，通过 HF 国内镜像下载和校验图像实验用权重，结果见 [本轮 HF 下载记录](HF镜像权重下载记录_20261119.md)。网盘和 release 页面仍只是下载集合入口，没有逐一验证或下载；其他下载方式继续暂缓。

统计口径补充：下文 124 是源码声明、兼容依赖导出和变体名称的技术清单，不是 124 种独立算法，也不是老师必做实验的数量。完整分类见 [ForensicHub 模型分类](ForensicHub模型分类_20261119.md)。本地官方跨域图像模板包含 21 个基础目标和 24 个变体；兼容库额外模型应在实验清单中单列来源与用途。

用户明确排除 Qwen 等生成式 LLM/VLM 及 8 个时序视频模型，规则见 [experiment_scope.yaml](../configs/experiment_scope.yaml)。当前项目纳入 **115 个名称条目**，源码中的 Qwen 1 项和时序视频 8 项共 **9 项属范围外**，不下载、不训练。项目内 18 个模型已有完整记录，另有 **97 个条目**尚无完整对应记录，其中 19 个存在已知适配阻塞。CLIPDetector 等视觉图像模型继续保留，LSDA、UCF 的图像批次配对监督也保留。

```bash
python tools/forensichub_coverage.py --json reports/forensichub_coverage_20261119.json
bash scripts/run_all.sh --dry-run --pending --runnable-only
```

`--runnable-only` 只排除配置中已知的接口阻塞；它列出的仍是**待进行真实权重、前向/梯度及显存预检的候选模型**。缺少本地依赖、权重或源码中的未发现问题仍可能阻止运行。配置覆盖完整不等于全部模型实验已经完成。

接入修正还包括：PSNet 原生 logits 使用 BCEWithLogits；APSC 从掩码分支计算图像标签损失，避免原分类头的 detach 截断主干梯度；MVSS 等模型显式指定实际执行的特征层；SparseViT 恢复原生 512 输入。MantraNet 构建使用当前训练设备，HiFi 的设备常量改为可迁移缓冲区。SPAN 原实现每次前向新建随机卷积头，FFDN 仍缺真实 JPEG 辅助输入，因此两者保留待适配状态。

`--pending` 同时读取手工验收记录与指定输出根目录的新训练元数据，只有轮数、有效 CSV、完成日志、最终权重及所需逐轮报告都齐全时，才把新模型排除出待跑清单。本机已通过静态覆盖、Python 编译、严格加载和标签适配验证，并用真实 Synthbuster 实现加合成四域数据跑通 10 轮 CPU 流程；依赖导入做了隔离，该验证不是额外的正式实验。本机缺少 timm、albumentations，完整模型依赖与真实任务权重的 GPU 预检仍需在既有实验环境进行。

## 7. 下载与启动约定

1. 下载权重放在 `weights/manual/<来源或领域>/`，骨干缓存放 `weights/hf/` 或 `weights/torch/`。不要下载到会清空的临时目录，不将大权重提交 Git。
2. HF 按交接设置使用 `snapshot_download` 或 `hf download`，镜像为 `https://hf-mirror.com`；先单进程准备缓存，再启动 DDP。本文的 HF 页面是资源入口，不要求用 `wget resolve` 下载。
3. 每个任务 checkpoint 保存来源、训练域、文件名和 SHA256；训练前核对目标子模块及严格加载记录。骨干初始化可按上游处理头部差异，但不能用宽松加载掩盖任务结构不匹配。
4. 统一 10 轮、seed 42、相同四域划分；batch 是每卡值，OOM 后降低 batch 并按全局 batch 调整学习率，不改变输入协议来伪造可跑记录。
5. 先逐模型完成 checkpoint 加载、诊断特征、可微损失和梯度预检，再开始完整实验；每个条目只有出现完整训练产物后才能从待完成改为完成。脚本静态检查或 CPU 预检通过不等于老师要求的全部实验已经完成。
